# 外部参考模板：已隔离

12 条资料已移至 reference_library/external_reference_cases.json，不在版本化 APX 知识挂载内。
它们是根据公开数据介绍构造的未核验模板，没有对应已下载、逐条核验的原始试验记录。因此不能称为真实历史案例或正确故障标签。

每条已标记 record_kind=unverified_reference_template、verification_status=source_record_not_verified、eligible_for_diagnosis=false。
默认检索、模型上下文、诊断证据和工单均不使用这些模板。原网址仅保留作将来核验线索；本轮未重新验证这些网站内容。

后续要引入真实记录，需核对原始记录编号、故障标签、工况、授权许可及与 APX 的适用范围，再独立评审。即使完成核验，也不能把其他设备标签当作 APX 当前根因。
