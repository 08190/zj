# 作业提交说明（待填真实入口后提交）

## 1. Agent访问入口

待部署及外部设备验收后填写正式HTTPS链接，访问账号单独提供。当前127.0.0.1地址仅限运行服务的本机，不能作为远程访问入口。不要把本文的待填写状态作为已完成提交。

## 2. 支持的输入

文字故障描述：报警码、现场温度/电流/压力、可见异常、发生时间等。支持后续补充和读数更正。题目PDF已作为固定知识库载入；不支持任意图片识别或上传其他设备资料后自动诊断。

## 3. 如何使用给定规则

先执行手册安全规则，再精确识别报警码，同时在相关模块内检索手册和历史材料。每条来源保留编号、原文、页码和知识版本。OpenAI模型仅在已有候选中审阅风险、调整排序；不能生成手册之外的操作或批准复机。历史案例及维修记录不等于当前根因，外部未核验模板不参与诊断。

## 4. 输出字段

故障现象、已知事实、分层后的可能原因、证据来源、安全前置条件、排查顺序、需要补充的信息、一个最有价值的下一问、诊断变化、停止条件/专家升级。可下载结构化报告及维修工单草稿。无覆盖或证据冲突时停止进一步操作并建议专家复核；明确危险时先停机。

## 5. 自测样例

examples目录提供三组本版实际离线运行结果。它们证明规则流程运行，不代表最终线上模型验收：

- A203低温：现场信息完整时进入 `REPORT_READY`；把加热器开路和继电器/线路列为优先核查，把已排除的未预热与设定错误标成当前证据不支持；仍不确认H1损坏。
- A520金属摩擦：进入 `SAFE_BLOCKED`，立即停机并升级专家，安全门在远程模型之前阻断。
- A310气压低：进入 `INFO_REQUIRED`，突出“上游压力”为下一步最有价值的问题，保留多个手册候选原因。

提交前应另外保存最终入口上的真实模型输入输出，至少1组，建议上述3组。不能把离线结果标成真实OpenAI结果。
